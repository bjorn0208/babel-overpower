# PABX — artefato público publicado

Captura HTTP de `https://babel-pabx.vercel.app`, título BabelPhone. `artefato/` contém HTML e assets referenciados recuperáveis; hashes e ocorrências estão em `manifesto.json`.

É o **build compilado**, não o repositório fonte editável nem uma integração ao frontend Babel. Não prova captura de todas as rotas, assets calculados dinamicamente, configuração da Vercel ou funcionamento das chamadas. API da equipe Vercel recusou acesso (403). Para desenvolvimento completo, ainda precisamos do projeto fonte PABX (`app/`, configurações e lockfile) e do código/configuração do VPS.
